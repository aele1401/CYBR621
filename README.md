# CYBR 621 - Secure Systems Programming

This repository contains coursework, labs, projects, and supporting materials for **CYBR 621: Secure Systems Programming**.

## Course Focus

The course focuses on applying secure programming principles to systems-level software and evaluating security throughout the software development process.

Topics and practical work include:

- Secure systems programming
- C programming and memory safety
- Secure coding practices
- Vulnerability identification and remediation
- Threat modeling
- AI-assisted software development
- Security analysis of AI-generated code
- Secure software development practices
- Practical testing and code review
